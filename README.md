# 초음파 공중부양 시뮬레이션

마주 보는 40 kHz 초음파 발생기 2개 사이의 정상파가 스티로폼 공을 붙잡는 현상을 계산하고 보여주는 웹 시뮬레이션입니다.
음향장 → Gor'kov 퍼텐셜 → 음향 방사력 → 공의 운동이 하나의 계산 흐름으로 이어지고, 각 단계를 해석해와 비교해 검증했습니다.
사양은 [`SPEC.md`](SPEC.md)에 있습니다.

**사이트: https://yanggeonwoo.github.io/-/**
(`main`에 push하면 GitHub Actions가 테스트 → 빌드 → `gh-pages` 브랜치로 자동 배포)

## 실행

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # physics 검증 (Vitest)
npm run build      # 타입 검사 + 배포용 빌드 (dist/)
```

`?noworker`를 붙이면 Web Worker 대신 메인 스레드에서 음향장을 계산합니다(디버깅용).

## 화면

- **메인 뷰**: x-z 단면 히트맵(압력 진폭 |P| / 퍼텐셜 U / 순간 압력 Re P(t)), 발생기, 마디 보조선(점선), 공.
  "힘 화살표"를 켜면 음향 방사력 + 중력(흰색)과 공이 받는 알짜힘(노란색)이 보입니다.
  순간 압력 애니메이션은 시각화용 1 Hz로 돌며 공의 운동 시간과는 관계없습니다.
- **축 위 퍼텐셜과 힘**: 축(x = 0) 위 U(z), F_z(z), mg 기준선, 공의 현재 z.
- **발생기 간격과 공진**: 공진 이득 G(d)와 현재 d. "가장 가까운 공진 거리로 맞추기"는 d를 λ/2의 정수배로 맞춥니다.
- **무게 늘리기**: 공 밀도를 서서히 늘려 이론 한계(F_max = mg) 근처에서 떨어지는지 보여줍니다(사양 외 추가 기능).
  속도 1× / 2× / 5× / 10×를 고를 수 있습니다(1×는 한계까지 약 20초). 배속은 무게 증가와 공의 운동을 같은 배율로 빨리 재생하므로 결과는 배속과 관계없이 같습니다.
  무게만 빨리 늘리면 공이 따라가지 못해 10×에서 한계의 190%를 넘어서야 떨어졌기 때문에 이렇게 만들었습니다.
  "떨어진 무게"는 공이 덫(마디 아래 λ/4)을 벗어나는 순간의 값이고, 그 뒤로는 무게를 고정합니다.
- 기본 조작: 공 놓기, 구동 세기, 간격 d, 공 지름·밀도, 위상차 φ, 힘 화살표. 나머지는 "고급 설정"에 있습니다.
- **점음원 지향성 (1 + cosθ)/2는 기본으로 켜져 있습니다**(`DEFAULT_DIRECTIVITY`). 실제 발생기에 가깝고, 면 근처 마디의 측면 불안정이 사라집니다(아래 "측면 안정성").
  보정(s_ref)은 지향성 설정별로 따로 구하므로 어느 쪽이든 기본 조건에서 P0 = 1500 Pa입니다.
  SPEC 6장 검증 테스트는 사양의 기준 모델인 지향성 off로 돌리고(`tests/helpers.ts`), 앱 기본값은 `tests/m7_defaults.test.ts`에서 따로 확인합니다.

## 구조

```
src/physics/   순수 계산 (React 의존 없음, Node에서 테스트)
  acoustics      음속, 파장, 공기 밀도
  gorkov         A층: 1차원 해석해, Gor'kov 퍼텐셜, F_max, 강성 κ
  resonance      공진 이득 G(d), 공진 거리 맞춤
  sourceSampling 원판 발생기 → 면적 가중 점음원
  field2d        B층: 2차원 압력장, 퍼텐셜/힘 격자, 축 위 1D 샘플
  calibration    구동 세기 보정 (s_ref, 앱 시작 시 한 번)
  integrator     C층: 속도 Verlet, 감쇠, 시간 간격
src/sim/       음향장 캐시(scene), 공 상태(ballSim), Web Worker
src/components 컨트롤, 수치, 메인 뷰, 사이드 그래프
tests/         검증 테스트 (m1~m6)
```

음향장은 두 단계로 나눠 계산합니다.

1. `buildField` (무거움, Web Worker): 점음원 합으로 2D 격자와 축 위 1D 샘플. f, T, d, a_t, φ, 지향성이 바뀔 때만 150 ms 디바운스 후 다시 계산합니다.
2. `finishScene` (가벼움, 약 1 ms): 실제 세기, 퍼텐셜/힘 격자, 수치. 구동 세기, 공, R, ζ를 바꾸면 즉시 반영됩니다.

공의 위치와 속도는 React 상태에 넣지 않고 `useRef`로 들고, `requestAnimationFrame` 루프에서 Canvas에 직접 그립니다.

추가로 확인한 것:

- 기본 조건에서 F_max/mg = 28.3이므로 공은 지금 무게의 약 29.5배까지 버틸 수 있다고 해석식은 예측합니다. 무게 늘리기 시뮬레이션(2차원 장)에서는 이론 한계의 92%(구동 1.0)와 86%(구동 0.5)에서 덫을 벗어났습니다. 1×~10× 모든 배속에서 91~92%로 같았습니다.
- 2차원 모델(B층)의 축 방향 최대 힘은 해석식 F_max의 약 80%입니다(유한 크기 발생기의 근접장 효과).
- 공진 거리에서 λ/4 벗어나면 P0가 1500 Pa에서 482 Pa로 줄어듭니다(R = 0.5 가정).

## 측면 안정성 (검증 11)

**결론: 가운데 마디는 측면으로도 안정합니다. 면에 가까운 바깥 마디는 발생기가 크면 축 위에서 불안정하고, 공은 축에서 조금 떨어진 곳에 머뭅니다.**

마디에서 x = +0.3mm로 밀었을 때의 F_x/mg (지향성 off, 음수 = 복원):

| a_t \ d | 4·λ/2 | 5·λ/2 | 6·λ/2 | 8·λ/2 |
|---|---|---|---|---|
| 4 mm | −0.08 ×2 | −0.05 … −0.04 | −0.04 … −0.02 | −0.02 … −0.01 |
| 6 mm | −0.33 ×2 | −0.04, −0.20 | −0.13, −0.12 | −0.06 … −0.05 |
| 8 mm (기본) | −0.57 ×2 | **+0.12**, −0.50 | −0.18, −0.37 | −0.04 … −0.20 |
| 10 mm | **+1.01**, −0.45 | **+0.54**, −0.65 | −0.07, −0.63 | **+0.09**, −0.35 … −0.41 |

(각 칸은 바깥 마디, 가운데 마디 순서. 대칭이라 한쪽만 적음.)

- **가운데 마디**: 조사한 모든 조건에서 복원 방향입니다. 기본 조건에서 공을 놓는 곳(z ≈ 8.36 mm)은 F_x/mg = −0.50이고, x = 0.5mm에서 놓으면 축으로 돌아와 부양합니다.
- **바깥 마디**(면에서 약 0.4λ): a_t가 8mm 이상이면 축 위에서 F_x가 바깥을 향합니다. 기본 조건에서는 x ≈ 1.5mm까지 바깥으로 밀다가 그 너머에서 다시 복원되므로, 공은 **축에서 약 1.5mm 떨어진 곳에서 부양**합니다(실제 3차원에서는 고리 모양 평형).
- **원인**: 원판 반지름(8mm ≈ 0.93λ)에 비해 면과의 거리가 짧으면, 원판 가장자리에서 큰 각도로 오는 성분 때문에 근접장의 압력이 축 밖에서 극대가 됩니다. 점음원 개수나 격자 문제가 아니라는 근거는 두 가지입니다. 격자 힘과 격자 없이 직접 미분한 힘의 부호가 모든 점에서 일치하고, a_t를 줄이거나 간격을 늘리면 사라집니다.
- **지향성 (1 + cosθ)/2를 켜면** 큰 각도 성분이 약해져 바깥 마디도 복원 방향이 됩니다(F_x/mg = −0.02, 약함). 이때 바깥 마디에 놓은 공은 축으로 돌아옵니다.
- 실제 발생기는 지향성이 있으므로, 실험에 더 가까운 것은 지향성 on 쪽일 가능성이 높습니다. 다만 이 모델로는 확정할 수 없습니다. 이런 이유로 앱 기본값은 지향성 on입니다.

관련 테스트: `tests/m3_motion.test.ts`(검증 11), `tests/m6_lateral.test.ts`(스캔과 바깥 마디).

## 성능

계산 시간 (Node, 이 PC 기준):

| 조건 | 음향장 (`buildField`) | `finishScene` | 공 적분 (프레임당) |
|---|---|---|---|
| 기본 (113×92 격자, 점음원 92개) | 43~74 ms | 1.0 ms | 0.02 ms |
| d = 50mm, a_t = 10mm, 지향성 (113×224, 146개) | 180~210 ms | 1.2 ms | 0.02 ms |

브라우저 (헤드리스 Chrome, 1400×1300): 60.0 fps, 프레임 간격 중앙값 16.7 ms / 최대 17.2 ms.
순간 압력 애니메이션과 힘 화살표를 켜도 같고, 50 ms 이상 걸린 long task는 없었습니다.
음향장은 Web Worker에서 계산하므로 슬라이더를 끄는 동안에도 화면이 멈추지 않습니다.

## 한계

- 공 지름 3mm에서 ka ≈ 1.1이라 Gor'kov 근사(ka ≪ 1)가 엄밀하지 않습니다. **정량값이 아니라 경향을 보여주는 모델**입니다.
- 가정값: 반사계수 R = 0.5, 감쇠비 ζ = 0.1, 기준 압력 1500 Pa, 입자 체적탄성률 1e8 Pa. 공진 이득 G(d)는 다중 반사를 단순화한 모델입니다.
- x-z 단면(축대칭 가정)만 계산합니다. 공과 발생기 면 사이의 산란, 음향 유동, 공의 회전은 무시합니다.
- 면에서 λ/8 이내는 점음원 근사가 깨지므로 계산하지 않고, 이 구간에서는 음향 방사력을 0으로 둡니다.
- B층 힘은 격자(λ/40) 중앙 차분과 쌍선형 보간이라 해석값보다 약 2% 작을 수 있습니다.
- 실제 공기 저항만으로는 진동이 거의 멈추지 않으므로 유효 감쇠(가정값)를 씁니다. 공의 운동은 기본 0.05배속으로 재생됩니다.
- 면 근처 마디의 측면 안정성은 발생기 크기와 지향성 가정에 민감합니다(위 "측면 안정성").
